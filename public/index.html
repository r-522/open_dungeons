遊び方

このサイトはゲーム本体ではない。

本作はネイティブの Godot 製ゲーム。下記の手順でローカル環境にて起動する。

起動の手順

  1. Godot 4.3+（.NET 版） と .NET SDK 8.0 をインストールする。
  2. リポジトリを取得する：
    git clone https://github.com/r-522/open_dungeons
cd open_dungeons
dotnet restore
  3. Godot エディタを開く：godot --editor .
  4. 初回のみ プロジェクト → ツール → C# → C# ソリューションを作成。
  5. F5 で scenes/ui/Title.tscn から起動する。
  6. マルチプレイは「マルチプレイ」画面から ホスト開始 または 参加（UDP 27015）。
注意。 このサイト（Vercel 配信）はマーケティング用の静的ページであり、ブラウザ内でゲームを起動することはできない。Web ビルドは設計書§4.2 の通り長期スコープに置かれている。
